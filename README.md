# 📊 Business Potential Analyzer

> Веб-приложение для анализа конкурентной среды и оценки бизнес-потенциала на основе финансовых показателей

## ✨ Основные функции
- 🔍 Поиск компаний-конкурентов по **ОГРН** и **ОКВЭД**
- 📋 Отображение результатов поиска в интерактивной таблице
- ✅ Выбор компаний для детального сравнения
- ⚙️ Автоматический анализ по "Золотому правилу экономики"
- 📈 Визуализация результатов сравнения
